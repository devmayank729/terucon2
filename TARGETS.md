## How this file is kept (read this first)

1. **Before any task**, read this file and say which target(s) the task serves.
2. **After the task**, update it: the target's status and evidence, its "Remaining" list, the counts, the "Start here" order if it changed, and a dated line in the change log at the bottom. Say what was verified and what was not.
3. **Count only what is real.** A screen on hard-coded data, or a button that only changes its own state, is *Demo screen only*, never *Done*. *Done* means real logic that has run at least against mocks; it says so when nothing has run against live services.
4. **Evidence is a file path** (and line where useful) that someone can open. No evidence, no tick.
5. **One exception: work done outside this repo** (training, accounts, deals) can only be ticked on your word. It is marked **"per you"** with the date, and the evidence still to attach is listed beside it.

**Added (2026-11-04, thirty-first update): the catalogue's designs in the studio, without touching `swatchroom/`.** Full account: `docs/CATALOGUE_STUDIO.md`. (1) The studio's page loader is replaced by one that first asks `GET /api/catalogue/studio-finishes` (the designs, from MongoDB) and adds them to the studio's own finish list as a group **"Terucon catalogue"**, first in the list, for **wall, door and furniture** (one item id per kind, because the studio drops a finish whose kind is not the clicked surface's); the studio then starts whatever happened (at most 4 s of waiting; with the catalogue off or down it opens exactly as before). The design's real photograph is put on its card. These items have no instant preview (the preview needs a tileable texture; a photo of a sheet is not one): they render with the AI. (3) The brief is written from what Gemini saw in the picture (colours, pattern, which way it runs, how large its marks are, sheen, relief). **Evidence (live, real Gemini image model, the studio's own path; one clinic photo, one wall, one run per variant, two designs):** with name and colour only the marble came out as generic smoky stone and the teak as a pale blonde wood; with the description alone it was closer; with the description plus the photograph both had the sample's character (dense fine veins on a dark brown-black ground; deep amber-brown with fine vertical grain and small knots).
